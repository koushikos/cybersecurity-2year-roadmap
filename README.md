A structured 2-year Cybersecurity roadmap covering fundamentals, networking, ethical hacking, blue team, cloud security, tools, projects, and certifications — step-by-step from beginner to job-ready.


# 🔐 Cybersecurity 2-Year Roadmap (Zero → Job Ready)

This repository contains a structured 24-month roadmap to become a job-ready Cybersecurity Professional.  
It is designed for students and beginners who want step-by-step skill development with practical output.

Goal: Build strong fundamentals → hands-on skills → real projects → certifications → job readiness.

---

# 📅 Phase 1 — Foundations (Months 1–3)

## Core IT Basics
- Computer Networks fundamentals
- OS basics (Linux + Windows internals)
- How the Internet works
- TCP/IP, DNS, HTTP/HTTPS
- Virtualization basics

## Linux Fundamentals
- File system & permissions
- Users & groups
- Processes & services
- Networking commands
- Bash basics

## Programming Basics
- Python fundamentals
- Data Structures basics
- Scripting mindset

## Output
- Linux command notes repo
- Python automation scripts
- Networking concept notes

---

# 🌐 Phase 2 — Networking + Security Basics (Months 4–6)

## Networking Deep Dive

- Packet flow

## Security Fundamentals
- CIA Triad
- Threat, Risk, Vulnerability
- Types of attacks
- Encryption basics

## Tools
- Wireshark

- Netcat

## Output
- Network scan reports
- Packet analysis practice
- Security fundamentals notes

- 20% Projects

  - Notes

  - Lab report

- Strong fundamentals
